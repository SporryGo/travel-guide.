# SpottyGo Travel Guides — GitHub Pages starter

A responsive, static travel guide website that links readers to https://spottygo.com/.

## Files
- `index.html` — homepage
- `guides/` — starter travel guide pages, including Kumbh Mela
- `assets/style.css` — site styling
- `assets/script.js` — mobile menu and footer year

## Publish with GitHub Pages
1. Create a **public** repository named `spottygo-travel-guide` (or choose another name).
2. Upload all files and folders in this package to the repository root. Make sure `index.html` is at the top level, not inside another folder.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to finish publishing. The address will usually be:
   `https://YOUR-GITHUB-USERNAME.github.io/spottygo-travel-guide/`
7. Replace `YOUR-GITHUB-USERNAME` in the canonical link tags in every HTML file with your GitHub username. If you use a different repository name, update the repository part of those canonical URLs too.
8. Test the homepage and each guide link on mobile and desktop.

## Important notes
- This is a static site; it does not include hotel booking, user accounts, forms that send messages, or a database.
- `hello@spottygo.com` is included as a sample contact link. Change it if that is not a monitored address.
- Check facts, update articles regularly, and use official sources for current temple dates, registrations, road conditions and advisories.
- GitHub Pages is best used as a supporting guide site. Avoid publishing copied or near-duplicate pages solely to create backlinks; publish genuinely useful, distinct content.
- If you later want to use a custom domain, configure it through **Settings → Pages → Custom domain** and follow GitHub's DNS instructions.
